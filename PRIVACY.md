# Botna Privacy Notice

## Information stored on the device

Botna stores saved scripts, image templates, agent tasks, agent messages, and diagnostic logs in the app's private local storage. API keys are encrypted using Android Keystore-backed protection. Users can delete scripts and logs from within the app. Uninstalling the app generally removes its private local data.

## Information sent to service providers

When the user requests AI analysis, Botna sends the prompt and the data needed for the request to the provider configured in AI Settings. If screenshot context is enabled, the current screenshot may also be sent. Screenshots can contain private information. The provider's own privacy, retention, quota, and billing terms apply.

Botna can also contact endpoints explicitly configured by the user for API requests, internet checks, or URL-related automation.

## Accessibility and automation

The user must enable Botna's Accessibility service in Android Settings. While enabled, the service can inspect visible interface elements and perform supported actions requested through scripts or agent tasks. Users should supervise sensitive actions such as payments, purchases, account changes, sending messages, and deletion.

## Diagnostic logs and screenshots

Diagnostic logs are stored locally. Diagnostic screenshot capture can be disabled in the log settings. When enabled, a screenshot may be stored with a failure record to help explain what happened.

## Data sharing and contact

Botna does not send the user's API keys to the developer. AI request data is sent to the provider configured by the user. The app's behavior should be checked against the final release build and any added libraries before publication.
